This commits changes straight to your repo, so the site updates without you writing any HTML.

Use a fine-grained personal access token scoped only to the BeninDeCrazyProgrammer.github.io repository, with Contents: Read and write permission and a short expiry. Create one at github.com/settings/personal-access-tokens/new. The token stays only in this browser tab (cleared when you close it) and is sent only to api.github.com — never paste it anywhere else, and don't use this page on a shared computer.
